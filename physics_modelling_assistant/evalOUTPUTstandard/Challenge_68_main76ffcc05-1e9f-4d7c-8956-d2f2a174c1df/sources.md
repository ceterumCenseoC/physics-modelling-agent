

# Important Sources

1. **arxivID**: 1604.03089
   - **Author**: Fumio Hiai, Milan Mosonyi
   - **Date**: 2016-04-11
   - **URL**: https://arxiv.org/pdf/1604.03089v4
   - **Summary**: This definitive paper provides a unified framework for different quantum $f$-divergences, explicitly covering the standard Petz quasi-entropy formulation. It contains rigorous treatments of the integral representation involving the measure $\mu$, operator monotone functions, and detailed calculations of derivatives with respect to density matrix parameters, directly enabling the computation of $\frac{d}{dt} D^{\mathrm{std}}_f(\rho_t \|\sigma)$.

2. **arxivID**: 1008.2529
   - **Author**: F. Hiai, M. Mosonyi, D. Petz, C. Beny
   - **Date**: 2010-08-15
   - **URL**: https://arxiv.org/pdf/1008.2529v6
   - **Summary**: A foundational reference establishing the mathematical properties of quantum $f$-divergences. It details the spectral calculus and integral kernels required to handle the operator inverse $\frac{1}{L_\rho + s R_\sigma}$, and discusses differentiability, convexity, and continuity properties essential for analyzing the derivative along the linear path $\rho_t = \sigma + t(\rho - \sigma)$.

3. **arxivID**: 1710.10252
   - **Author**: Mark M. Wilde
   - **Date**: 2017-10-27
   - **URL**: https://arxiv.org/pdf/1710.10252v2
   - **Summary**: This work examines optimized quantum $f$-divergences and their behavior under quantum operations. It presents variational characterizations and derivative identities for quantum divergences, providing complementary analytical tools and consistency checks for modeling the calculus of the standard quantum $f$-divergence with respect to state variations.
