

Based on the theory of fractional disclination charges in $C_4$-symmetric topological crystalline insulators, the trapped fractional charge $Q_{\text{dis}}^{(4)}$ (in units of electron charge $e$) for a disclination with Frank angle $\Omega = -\pi/2$ is determined by the number of Wannier orbitals at the plaquette center ($n_b$) and the edge center ($n_c$) [1]. The translation-equivalence class $[a]^{(4)}$ dictates which formula applies:

$$Q_{\text{dis}}^{(4)} = \begin{cases} 
+\dfrac{n_b}{4} \pmod 1 & \text{for nontrivial class } ([a]^{(4)} = 1) \\[8pt]
-\dfrac{n_b + 2n_c}{4} \pmod 1 & \text{for trivial class } ([a]^{(4)} = 0)
\end{cases}$$

**1. Initial Configuration ($n_b=4, n_c=1$):**
* **Nontrivial class $([a]^{(4)}=1)$:** $Q = +4/4 = 1 \equiv \mathbf{0}$
* **Trivial class $([a]^{(4)}=0)$:** $Q = -(4 + 2(1))/4 = -1.5 \equiv \mathbf{-0.5}$

**2. With One Additional Band at 1b ($n_b=5, n_c=1$):**
* **Nontrivial class $([a]^{(4)}=1)$:** $Q = +5/4 = 1.25 \equiv \mathbf{0.25}$
* **Trivial class $([a]^{(4)}=0)$:** $Q = -(5 + 2(1))/4 = -1.75 \equiv \mathbf{0.25}$

All values are normalized to the interval $[-1/2, 1/2)$ as requested.
