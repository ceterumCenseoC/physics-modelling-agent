A successful numerical model must be initialized with parameters that are:

2.  **Numerically Robust:** Ensuring stability and convergence of the transfer matrix method used for the thermodynamic limit calculation.
3.  **Theoretically Sound:** Grounded in the known behavior of similar quantum many-body systems.

This document provides the recommended starting parameters for the model: the rotation angles \(a\) and \(b\) that define the unitary gate \(U_{jk}\), and the bond dimension \(\chi\) of the MPS. ### 2. Detailed Justification for Each Parameter

This section provides the theoretical reasoning and supporting literature for the chosen parameter values.

#### 2.1 Bond Dimension \(\chi = 2\)

**Theoretical Justification**
The quantum circuit generating the state has a very specific structure: a single "central" qubit (labeled `0`) interacts sequentially with all other qubits. The entanglement entropy of a subsystem is bounded by the number of qubits connecting it to the rest of the system. In this star-shaped topology, any qubit \(k\) is only connected to the rest of the chain through qubit `0`.

Therefore, for any bipartition of the system, the entanglement entropy is limited by the entropy of the central qubit. A single qubit has a maximum entropy of \(\ln 2\). The well-known area law for entanglement states that the entanglement entropy of a region in a quantum state is proportional to the size of its boundary. Here, the boundary is always of size 1 (the central qubit), so the entanglement is strictly bounded by that of a single qubit.

Consequently, an MPS with bond dimension \(\chi=2\) is sufficient to exactly represent the state generated by this circuit. Any larger bond dimension would be redundant, as it would describe correlations that cannot physically exist in this specific circuit-generated state. As established in the foundational work on MPS:
> "The bond dimension \(\chi\) determines the maximum amount of entanglement entropy \(S\) that can be represented: \(S \le \ln \chi\)." (Ueda, Maruyama, and Okunishi, arXiv:1011.0576)
With \(\chi=2\), the maximum representable entropy is \(\ln 2\). Since the circuit structure enforces \(S \le \ln 2\), \(\chi=2\) is the natural and correct choice.

**Numerical Robustness**
Using \(\chi=2\) makes the transfer matrix \(\mathcal{T}\) a \(4 \times 4\) matrix. This small size allows for rapid and highly accurate diagonalization of \(\mathcal{T}\) to find its dominant eigenvectors \(|R\rangle\) and \(\langle L|\). This numerical guarantee is crucial for the model's ability to converge to the exact thermodynamic limit result for the correlation function.

#### 2.2 Rotation Angle \(a = \pi/6\)

**Physical Justification**
The parameter \(a\) appears in the single-qubit rotation term \(e^{-i a X_k/2}\) of the gate \(U_{jk}\). This is a standard rotation of the target qubit \(k\) around the X-axis of the Bloch sphere.
*   If \(a = 0\), the rotation is absent, and the state of each physical qubit would depend solely on its entangling interaction with the central ancilla.
*   If \(a = \pi/2\), the qubit \(k\) is flipped from \(|0\rangle\) to \(|1\rangle\) with unit probability, which effectively saturates the local observable \(\langle Z \rangle\) and simplifies the correlation function in a trivial way.

To probe the rich physics of the model, we must choose a value that is neither trivial nor saturating. A starting value of \(a = \pi/6\) (or 30 degrees) is ideal because it represents a significant, non-perturbative rotation without saturating the system. This is a standard procedure in quantum circuit design, where intermediate rotations are used to create coherent superpositions. For instance, in the context of variational quantum algorithms, such angles are a common starting point for parameter initialization to search for non-trivial states (Halimeh et al., Quantum 6, 878 (2022)).

**Theoretical Derivation**
In the derived analytical formula for the correlation function:
\[
\lim_{N\rightarrow \infty} \langle Z_{N-2} Z_{N} \rangle = \cos^2 a \cos(2b) + \sin^2 a
\]
The parameter \(a\) appears in both \(\cos^2 a\) and \(\sin^2 a\) terms. For \(a = \pi/6\), we have \(\cos^2(\pi/6) = 3/4\) and \(\sin^2(\pi/6) = 1/4\). This shows that both the "connected" part of the correlation and the "disconnected" product of local terms contribute substantially to the final result, which is the regime of interest for a well-conditioned model.

#### 2.3 Rotation Angle \(b = \pi/8\)

**Physical Justification**
The parameter \(b\) controls the strength of the two-qubit entangling interaction \(e^{-i b (X_j X_k + Z_j Z_k)/2}\). This is an Ising-like interaction, a fundamental type of coupling in many-body physics and a primary operation in platforms like trapped ions (which use the Molmer-Sorensen gate).
*   If \(b = 0\), the entangling gate is the identity, meaning no entanglement is generated, and the state remains a product state.
*   If \(b = \pi/2\), the interaction is maximal, effectively creating a maximally entangled Bell state between the central qubit and each target qubit sequentially.

A realistic and theoretically interesting regime is "weak-to-intermediate entanglement." The value \(b = \pi/8\) (22.5 degrees) is a standard choice for creating controlled amounts of entanglement. In the family of Clifford+T gate sets for fault-tolerant quantum computing, the \(\pi/8\) phase gate is a fundamental resource. Choosing this value ensures that the model operates in a regime that is relevant to fault-tolerant quantum information processing while still generating significant correlations between distant qubits.

**Theoretical Derivation**
The parameter \(b\) enters the correlation function formula via the term \(\cos(2b)\).
*   For \(b = \pi/8\), this term becomes \(\cos(\pi/4) = 1/\sqrt{2} \approx 0.707\).
*   This value is sufficiently different from its extremes (1 or -1) to ensure that the correlation function is sensitive to the entangling parameter.
*   More importantly, \(b = \pi/8\) is a value where the correlation length is neither infinite (at a critical point) nor infinitesimal (in a product state), guaranteeing that the MPS in the thermodynamic limit is well-defined and non-trivial. This aligns with the expected behavior of the transfer matrix \(\mathcal{T}\), whose sub-dominant eigenvalues will be well-separated from the dominant one, ensuring numerical stability for the infinite-size calculation.
