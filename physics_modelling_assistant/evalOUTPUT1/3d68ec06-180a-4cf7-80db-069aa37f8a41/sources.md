

# Relevant Papers on Weingarten Calculus for Orthogonal Groups

**1. The Weingarten Calculus**
*   **arxivID**: 2109.14890
*   **Author**: Benoit Collins, Sho Matsumoto, Jonathan Novak
*   **date**: 2021-09-30
*   **url**: https://arxiv.org/abs/2109.14890
*   **short summary**: A comprehensive and recent introduction to Weingarten calculus, detailing the computation of joint moments of matrix variables under the Haar measure of compact groups. It provides the necessary theoretical framework for integrating polynomials over the orthogonal group $O(d)$, which is central to solving the problem involving random operators $O$.

**2. On some properties of orthogonal Weingarten functions**
*   **arxivID**: 0903.5143
*   **Author**: Benoît Collins, Sho Matsumoto
*   **date**: 2009-03-30
*   **url**: https://arxiv.org/abs/0903.5143
*   **short summary**: Presents a Fourier-type formula specifically for orthogonal Weingarten functions. This paper is fundamental for deriving explicit expressions for integrals of polynomials with respect to the Haar measure on the orthogonal group, directly applicable to the calculation of moments of the random operator $O$.

**3. Weingarten Calculus and the IntHaar Package for Integrals over Compact Matrix Groups**
*   **arxivID**: 1612.07641
*   **Author**: Alejandro Ginory, Jongwon Kim
*   **date**: 2016-12-16
*   **url**: https://arxiv.org/abs/1612.07641
*   **short summary**: Provides uniform formulas and a computational package (IntHaar) for evaluating integrals over unitary, orthogonal, and symplectic groups. It simplifies the integration formulas and offers optimizations for practical calculation of moments required in the problem setup.

**4. Moments of a single entry of circular orthogonal ensembles and Weingarten calculus**
*   **arxivID**: 1104.3614
*   **Author**: Sho Matsumoto
*   **date**: 2011-04-19
*   **url**: https://arxiv.org/abs/1104.3614
*   **short summary**: Focuses on the moments of single entries of symmetric unitary random matrices (circular orthogonal ensembles) using Weingarten calculus. This work provides explicit values and leading terms for moments, serving as a direct analog for calculating the expected values of matrix elements in the given problem.

**5. Weingarten calculus via orthogonality relations: new applications**
*   **arxivID**: 1701.04493
*   **Author**: Benoît Collins, Sho Matsumoto
*   **date**: 2017-01-17
*   **url**: https://arxiv.org/abs/1701.04493
*   **short summary**: Discusses new applications of Weingarten calculus for computing moments of the Haar measure on compact subgroups of matrix algebras. It extends the method's utility for theoretical physics problems involving random matrix ensembles similar to the orthogonal group case in the problem.
