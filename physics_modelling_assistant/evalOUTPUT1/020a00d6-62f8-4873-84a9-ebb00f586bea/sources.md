

# Relevant Sources for Continuous-Time Quantum Walk on Blown-Up Simplex Graphs

1. **arxivID**: 1501.07071
- **Author**: Thomas G. Wong
- **date**: 2015-01-28
- **url**: https://arxiv.org/abs/1501.07071
- **short summary**: This paper is the most directly relevant as it explicitly analyzes spatial search on the exact graph structure described in the problem: a "simplex of $K_M$ complete graphs" (mathematically equivalent to replacing each vertex of a simplex with a complete graph/clique). It provides a complete analytical solution for the continuous-time quantum walk on this topology, deriving the optimal spectral gap, tunable parameter $\gamma$, evolution time $T$, and success probability $P$.

2. **arxivID**: 1807.05957
- **Author**: Shantanav Chakraborty, Leonardo Novo, Jérémie Roland
- **date**: 2018-07-16
- **url**: https://arxiv.org/abs/1807.05957
- **short summary**: Presents a unified framework for finding a marked node on arbitrary graphs using continuous-time quantum walks. It establishes necessary conditions for quadratic speedup and provides a systematic subspace decomposition method for the Hamiltonian $H=-\gamma A-|a\rangle\langle a|$, which is essential for calculating the precise evolution time $T$ and concentration probability $P$ for high-dimensional clustered graphs.

3. **arxivID**: 2004.12686
- **Author**: Shantanav Chakraborty, Leonardo Novo, Jérémie Roland
- **date**: 2020-04-27
- **url**: https://arxiv.org/abs/2004.12686
- **short summary**: Investigates the fundamental optimality limits of spatial search via continuous-time quantum walks. The paper discusses rigorous bounds on the evolution time and achievable probability, offering theoretical verification tools to ensure the calculated $T$ and $P$ values for the $M=200$ case align with optimal quantum search complexity bounds.

4. **arxivID**: 2310.14141
- **Author**: Pedro H. G. Lugão, Renato Portugal
- **date**: 2023-10-22
- **url**: https://arxiv.org/abs/2310.14141
- **short summary**: A very recent study examining quantum search on combinatorial $t$-designs and complete multipartite graphs (which structurally match the problem's blown-up simplex) using continuous-time quantum walks. It provides updated analytical techniques for handling large-scale symmetric graph structures and derives explicit formulas for optimal search parameters.

5. **arxivID**: 2404.01640
- **Author**: Honghong Lin, Yun Shang
- **date**: 2024-04-02
- **url**: https://arxiv.org/abs/2404.01640
- **short summary**: The most recent paper in the list, presenting a deterministic search algorithm on complete bipartite and multipartite graphs via continuous-time quantum walks. It extends modern optimization techniques for the parameter $\gamma$ and discusses exact evolution protocols to maximize amplitude concentration at the marked vertex $|a\rangle$, offering cutting-edge validation for the problem's setup.
