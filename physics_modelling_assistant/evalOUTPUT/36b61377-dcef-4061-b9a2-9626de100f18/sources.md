

# Important Sources

1. **arxivID:** 1712.07579
   - **Author:** V. Bytev, B. Kniehl, S. Moch
   - **Date:** 2017-12-18
   - **URL:** https://arxiv.org/abs/1712.07579
   - **Short Summary:** Provides explicit formulas and series representations for the derivatives of Horn-type hypergeometric functions (which include the Gaussian ${}_2F_1$ as a single-variable special case) with respect to their numerator and denominator parameters. Highly relevant for computing $\partial/\partial n$ when $n$ appears inside the parameters of ${}_2F_1$.

2. **arxivID:** 2104.09140
   - **Author:** Ayman Shehata, Recep Sahin, Oguz Yagcı, Shimaa I. Moustafa
   - **Date:** 2021-04-19 *(Very Recent)*
   - **URL:** https://arxiv.org/abs/2104.09140
   - **Short Summary:** Derives explicit expressions for first and higher-order derivatives of Srivastava's hypergeometric functions with respect to parameters using properties of the Gamma function and Pochhammer symbols. Demonstrates techniques for parameter differentiation that can be adapted to standard ${}_2F_1$ functions.

3. **arxivID:** 2104.05051
   - **Author:** Ayman Shehata, Recep Sahin, Oguz Yagcı, Shimaa I. Moustafa
   - **Date:** 2021-04-11
   - **URL:** https://arxiv.org/abs/2104.05051
   - **Short Summary:** Investigates derivatives of Humbert confluent hypergeometric functions with respect to parameters. While focused on confluent types, the methodological framework for handling parameter derivatives and simplifying the resulting harmonic/digamma sums is directly transferable to non-confluent ${}_2F_1$ problems.

4. **arxivID:** 1705.02493
   - **Author:** D. B. Karp, E. G. Prilepkina
   - **Date:** 2017-05-06
   - **URL:** https://arxiv.org/abs/1705.02493
   - **Short Summary:** Compiles integral representations (Stieltjes and Laplace transforms) of generalized hypergeometric functions. These integral forms are extremely useful for evaluating parameter derivatives at specific points (like $n=0$) by differentiating under the integral sign, often simplifying the calculation to standard integrals.
