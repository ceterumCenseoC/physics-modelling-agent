

# Relevant Sources for AKLT Model and String Order Parameter Analysis

Based on the Hamiltonian provided (the spin-1 bilinear-biquadratic model, specifically the AKLT point) and the target quantity (string order parameter $\mathcal{S}_0$ under noise), the following papers are recommended. They are sorted by relevance to the specific problem of characterizing the ground state and the string order in this model.

- **arxivID:** 2402.00127
- **Author:** Wen-Tao Xu, Frank Pollmann, Michael Knap
- **Date:** 2024-01-31
- **URL:** https://arxiv.org/abs/2402.00127
- **Short Summary:** This **very recent** paper investigates the critical behavior of Fredenhagen-Marcu string order parameters at topological phase transitions. It provides advanced theoretical context for evaluating non-local string order parameters (like the $\mathcal{S}_0$ in the problem) as diagnostics for Symmetry Protected Topological (SPT) phases, which is essential for understanding the robustness of the AKLT state.

- **arxivID:** 2011.05452
- **Author:** Sudipto Singha Roy, Silvia N. Santalla, Javier Rodríguez-Laguna, Germán Sierra
- **Date:** 2020-11-10
- **URL:** https://arxiv.org/abs/2011.05452
- **Short Summary:** This paper focuses on the bulk-edge correspondence in the Haldane phase of the bilinear-biquadratic spin-1 Hamiltonian. It is highly relevant as it deals directly with the specific Hamiltonian $H$ in the problem (at the AKLT point) and characterizes the ground state $\rho_0$ properties necessary for calculating the initial trace before noise is applied.

- **arxivID:** 1707.01953
- **Author:** Ido Niesen, Philippe Corboz
- **Date:** 2017-07-06
- **URL:** https://arxiv.org/abs/1707.01953
- **Short Summary:** Using infinite projected entangled pair states (iPEPS), this study maps out the ground state phase diagram of the spin-1 bilinear-biquadratic Heisenberg model. It serves as a strong reference for modeling the exact ground state $\rho_0$ and understanding the phase transitions of the Hamiltonian defined in the problem setup.

- **arxivID:** cond-mat/0609051
- **Author:** F. Anfuso, A. Rosch
- **Date:** 2006-09-04
- **URL:** https://arxiv.org/abs/cond-mat/0609051
- **Short Summary:** This foundational paper discusses string order and adiabatic continuity in Haldane chains. It provides the theoretical basis for the string correlation functions $\langle R_z^{\otimes l} \rangle$, establishing the exact value of the order parameter in the noiseless limit, which is the baseline required to analyze the noisy state $\rho$.
