

# Important Sources for Research

Below are the selected relevant papers to assist in evaluating the derivative of the hypergeometric function with respect to the parameter $n$. The sources are sorted by relevance to the problem setup.

- **arxivID**: 1712.07579
- **Author**: V. Bytev, B. Kniehl, S. Moch
- **Date**: 2017-12-18
- **URL**: [https://arxiv.org/pdf/1712.07579v1](https://arxiv.org/pdf/1712.07579v1)
- **Short summary**: This paper is highly relevant as it explicitly considers the **derivatives of Horn-type hypergeometric functions with respect to their parameters**. Since the Gaussian hypergeometric function ${}_2F_1$ is a special case of these functions, the formulas provided here for the partial derivatives with respect to numerator parameters ($a$ and $b$) are directly applicable to solving for $\frac{\partial}{\partial n} f(n, \alpha)$.

- **arxivID**: 1705.02493
- **Author**: D. B. Karp, E. G. Prilepkina
- **Date**: 2017-05-06
- **URL**: [https://arxiv.org/pdf/1705.02493v2](https://arxiv.org/pdf/1705.02493v2)
- **Short summary**: This paper discusses **Stieltjes and Laplace transform representations** of hypergeometric functions. These integral representations are crucial tools for evaluating derivatives with respect to parameters by moving the derivative operator inside the integral sign, which can simplify the evaluation of the specific function $f(n, \alpha)$ at $n=0$.

- **arxivID**: 2104.09140
- **Author**: Ayman Shehata, Recep Sahin, Oguz Yagcı, Shimaa I. Moustafa
- **Date**: 2021-04-19
- **URL**: [https://arxiv.org/pdf/2104.09140v3](https://arxiv.org/pdf/2104.09140v3)
- **Short summary**: This study investigates derivatives with respect to parameters of **Srivastava's hypergeometric functions**, which generalize the Gaussian hypergeometric function. The methods used to derive explicit formulas for first-order derivatives with respect to parameters using Pochhammer symbols are directly transferable to the problem at hand.

- **arxivID**: 2104.05051
- **Author**: Ayman Shehata, Recep Sahin, Oguz Yagcı, Shimaa I. Moustafa
- **Date**: 2021-04-11
- **URL**: [https://arxiv.org/pdf/2104.05051v3](https://arxiv.org/pdf/2104.05051v3)
- **Short summary**: This paper focuses on the derivatives of **Humbert confluent hypergeometric functions** with respect to their parameters. It provides systematic methods for handling numerator and denominator parameters, offering additional context and techniques for differentiating hypergeometric series structures similar to the one in the problem setup.

- **arxivID**: 2507.19048
- **Author**: Hironobu Kimura
- **Date**: 2025-07-25
- **URL**: [https://arxiv.org/pdf/2507.19048v1](https://arxiv.org/pdf/2507.19048v1)
- **Short summary**: Included as a **very recent paper (2025)** to satisfy the recency requirement. It defines "Radon hypergeometric functions" and discusses their properties on Grassmannian manifolds. While the mathematical setting (Radon transforms) differs from the scalar problem provided, it offers a modern perspective on the definition and classification of hypergeometric functions.
