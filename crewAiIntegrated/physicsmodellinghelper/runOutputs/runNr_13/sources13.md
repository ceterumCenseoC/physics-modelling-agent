

# Edelstein Effect Research Papers for Rashba Fermion Modeling

## Top 3 Most Relevant Sources

### 1. **Edelstein Effect in Isotropic and Anisotropic Rashba Models**

| Field | Value |
|-------|-------|
| **arxivID** | 2503.20712 |
| **Authors** | Irene Gaiardoni, Mattia Trama, Alfonso Maiellaro, Claudio Guarcello, Francesco Romeo, Roberta Citro |
| **Date** | 2025-03-26 |
| **URL** | https://arxiv.org/pdf/2503.20712v1 |

**Summary:** This paper investigates spin-to-charge conversion via the Edelstein effect in a 2D Rashba electron gas using the semiclassical Boltzmann approach. It analyzes the magnetization arising from the direct Edelstein effect, taking into account an anisotropic Rashba model. The study examines how this effect depends on various model parameters including the Fermi velocity, Rashba coupling strength, and anisotropy. This is directly relevant for calculating the Edelstein effect at the Gamma point and understanding how magnetization magnitude and direction depend on applied electric field parameters.

### 2. **Theory of the nonlinear Rashba-Edelstein effect**

| Field | Value |
|-------|-------|
| **arxivID** | 1506.08330 |
| **Authors** | Giovanni Vignale, I. V. Tokatly |
| **Date** | 2015-06-27 |
| **URL** | https://arxiv.org/pdf/1506.08330v1 |

**Summary:** This paper provides a theoretical framework for the Edelstein effect in a two-dimensional electron gas with Rashba spin-orbit coupling. It examines the phenomenon beyond the linear response regime, exploring how current-driven spin polarization depends on the average drift velocity and other parameters. The work derives analytical expressions that relate the induced spin polarization to the applied electric field, Fermi velocity, and Rashba coupling constant, making it essential for modeling the magnetization magnitude and direction under varying electric field conditions.

### 3. **Boltzmann theory of the inverse Edelstein effect in a two-dimensional Rashba gas**

| Field | Value |
|-------|-------|
| **arxivID** | 2601.02473 |
| **Authors** | Irene Gaiardoni, Mattia Trama, Alfonso Maiellaro, Claudio Guarcello, Francesco Romeo, Roberta Citro |
| **Date** | 2026-01-05 |
| **URL** | https://arxiv.org/pdf/2601.02473v1 |

**Summary:** This paper investigates the Edelstein effect in a non-homogeneous system consisting of a ferromagnetic layer coupled to a Rashba two-dimensional electron gas. Within a semiclassical Boltzmann framework, it derives analytical expressions for charge and spin currents and analyzes their dependence on model parameters. The work provides detailed relationships between the induced magnetization, Fermi velocity, Rashba coupling strength, and applied electric field, which are crucial for building a comprehensive model of the Edelstein effect for Rashba fermions at the Gamma point of the Brillouin zone.

## Key Parameters for Model Building

Based on these sources, the following parameters should be considered when building the Edelstein effect model:

| Parameter | Symbol | Description |
|-----------|--------|-------------|
| Rashba coupling strength | $\alpha_R$ | Determines the spin-orbit interaction strength |
| Fermi velocity | $v_F$ | Characterizes electron velocity at Fermi surface |
| Fermi momentum | $k_F$ | Momentum at Fermi level |
| Electric field | $\vec{E}$ | Applied field magnitude and direction |
| Relaxation time | $\tau$ | Scattering time for electrons |
| Chirality | $\chi = \pm 1$ | Determines spin-momentum locking direction |

The Edelstein effect induces a spin polarization $\vec{S}$ proportional to the electric field:

$$\vec{S} \propto \alpha_R \tau \vec{E} \times \hat{z}$$

where $\hat{z}$ is the direction perpendicular to the 2D plane.
